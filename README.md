# UnknownBear Translation Hub

Official catalog and update distribution repository for **UnknownBear** Japanese Visual Novel localizations.

This repository serves as the cloud backend and catalog feed for the **UnknownBear Translator**.

---

## 🎮 How It Works

UnknownBear provides 1-click differential patchers (`.ubp`) that localize Japanese visual novels and games directly on your PC:
* **Zero Piracy:** Patches contain only translated scripts, graphical assets, and engine hooks. Players provide their own legitimate Japanese game copies.
* **Save Protection:** Existing game saves and configurations are automatically preserved during patching and updates.
* **Engine Native:** Japanese locale emulation is handled directly at the engine level—no Windows system locale switching required.

---

## 🚀 Getting Started

1. Download the **[UnknownBear Translator Downloader](https://github.com/Unknownbear99/UnknownBear-Hub/releases/tag/downloader-v1.0.0)** or grab it directly from our **[Patreon](https://patreon.com/UnknownBear)**.
2. Run the downloader to fetch the latest **UnknownBear Translator**.
3. Select your Japanese game folder or archive, pick your patch from the live Cloud Catalog, and click **Patch**!

## 📦 What's In This Repository?

* `catalog.json` — Live index of all released game translation patches and metadata.
* `app_manifest.json` — Version manifest for client updater checks.
* **[Releases](https://github.com/Unknownbear99/UnknownBear-Hub/releases)** — Hosted binary builds of the Translator, Downloader, and `.ubp` patch archives.
